# 공간·조명 연출 가이드

- 담당: 공간·조명(송지우)
- 교수님 피드백 대응: 1번 유리지붕 비, 2번 타이틀·엔딩, 4번 '뭔가 이상한' 분위기, 그리고 복도 꾸미기와 촬영 연출
- 전부 Play할 때 코드로 만들어지고 씬에는 저장되지 않는다. 씬에는 컴포넌트만 붙인다.

| 파일 | 내용 |
| --- | --- |
| `Assets/Scripts/Weather/` | 비 (`SkylightRain`), 천장 누수 (`CeilingDrip`), 젤리빈 이상현상 (`CeilingLeakAnomaly`) |
| `Assets/Scripts/Look/` | 분위기 (`AtmosphereLook`), 새벽 엔딩 (`DawnEnding`), 엔딩 화면 (`EndingCard`), 글꼴 (`FontRestyle`), 촬영 연출 (`PhotoFlash`). 자체 asmdef(`NightPatrol.Look`)라 기존 asmdef는 안 건드림 |
| `Assets/Shaders/Weather/` | 빗줄기, 젖은 유리, 바닥 빗물 그림자, 웅덩이 셰이더 |
| `Assets/Fonts/GowunBatang-*.ttf` | 고운바탕 (OFL 무료 글꼴, 자주 쓰는 한글 2,350자만 남겨 용량을 줄임) |
| `Assets/Textures/Posters/Poster_NP_*.png` | 복도 포스터 12장 |

## 한 번에 붙이기

**Floor5 씬**
1. FloorGenerator 오브젝트: `SkylightRain`, `DawnEnding`
2. 아무 오브젝트(예: PatrolSystems): `AtmosphereLook`, `PhotoFlash`, `EndingCard` (EndingCard의 Title Font = GowunBatang-Bold, Body Font = GowunBatang-Regular)
3. 화장실 앞 천장 아래 빈 오브젝트: `CeilingDrip`
4. FloorGenerator → 포스터 섞기 (또는 Generate Floor). 새 포스터가 자동으로 섞여 들어간다.

**Title 씬**
1. Canvas: `FontRestyle` (Title Font = GowunBatang-Bold, Body Font = GowunBatang-Regular)

## 1. 유리지붕 비 (`SkylightRain`)

5층 유리지붕에만 비가 보이고, 빗소리는 모든 층에서 들린다(아래층은 작고 먹먹하게).

들어가는 것:
- 빗줄기와 유리에 튀는 방울
- 빗물이 흘러내리는 유리 (방울 자리는 뒤가 굴절돼 보임)
- 바닥에 일렁이는 빗물 그림자

Rain Loop 칸에 빗소리 파일을 넣으면 소리가 난다. 생성기가 만든 `Skylight` 아래에 붙어서 아래층에서는 자동으로 꺼진다.

## 2. 천장 누수 · 젤리빈 이상현상

- **`CeilingDrip`:** 물방울이 똑똑 떨어지고 바닥에 웅덩이와 물결이 생긴다. 바닥은 레이로 자동으로 찾는다. 모든 층에서 쓸 수 있다.
- **`CeilingLeakAnomaly`:** 이상현상 담당용. 이상일 때 물 대신 젤리빈이 떨어져 흩어지고, 촬영되면 치워진 뒤 다시 물이 샌다. 연결 방법은 다음과 같다.
  1. CeilingDrip 오브젝트에 붙인다.
  2. Patrol Target에 PatrolObject를 넣는다.
  3. AnomalyManager에 후보 칸을 추가해서 넣는다.

  촬영 대상(PhotoTarget)은 웅덩이 자리에 자동으로 붙는다.

## 3. 분위기 (`AtmosphereLook`)

어둡게 만들지 않고, 형광등 아래 살짝 바랜 색과 옅은 안개로 '뭔가 이상한' 느낌을 만든다.

- **색:** 채도를 조금 빼고, 형광등 같은 초록·노란 기운과 필름 그레인, 옅은 비네트를 넣는다.
- **안개:** 복도 먼 곳이 흐려져서 이상현상이 멀리서 다 보이지 않는다. 팀에서 나온 '멀리서 다 보여서 긴장감이 없다'는 문제를 이걸로 푼다.
- **층별 변화:** 5층은 약하게 시작해서 2층으로 내려갈수록 조금씩 더 이상해진다. 화면이 아주 살짝 휘고 색이 번진다. 1층(엔딩)에서는 걷히면서 평범해진다.
- **소리:** Hum Loop에 형광등 웅웅 소리를 넣으면 깔린다.

조절 값:

| 값 | 기본 | 설명 |
| --- | --- | --- |
| Top / Last Floor Strength | 0.6 / 1.3 | 5층과 2층의 세기. 0이면 효과 없음 |
| Fog Range | (9, 32) | 세기 1일 때 안개 시작·끝 거리(m) |
| Saturation · Tint · Grain | -14 · -10 · 0.22 | 색감 |

메인 카메라의 Post Processing을 자동으로 켠다. 끄고 싶으면 Enable Camera Post Processing을 해제한다.

## 4. 엔딩 (`DawnEnding`, `EndingCard`)

- **`DawnEnding`:** 1층에 도착해 정문으로 걸어 나가는 동안 해가 뜬다. 하늘이 밝아지고, 출구 쪽 낮은 곳에서 주황빛 해가 올라오고, 주변광이 따뜻해진다. 해가 오는 쪽이 다르면 Sun From을 바꾼다(기본 +X = 동쪽 끝 출구). Morning Loop에 새소리를 넣으면 서서히 커진다. 하늘 머티리얼은 복사해서 쓰므로 원본 NightSky.mat은 바뀌지 않는다.
- **`EndingCard`:** 밖으로 나가 화면이 어두워지면 기존 '근무 종료' 위에 덮어서 아래 화면을 띄운다. 문구는 Inspector에서 바꿀 수 있다.

  ```
  06:00
  근무 종료
  특이사항: 없음
  ```

## 5. 글꼴 (`FontRestyle`)

Title 씬 Canvas에 붙이면 큰 글자(60 이상)는 제목 글꼴로 바뀌고, 자간이 넓어지고, 색이 살짝 바랜 흰색이 된다. 나머지 글자는 본문 글꼴로 바뀐다.

- 실행 중에 TMP 글꼴을 만들어서 SDF를 따로 구울 필요가 없다.
- 새 글꼴에 없는 글자는 원래 NotoSansKR로 보인다.
- 특정 글자만 바꾸려면 Auto By Size를 끄고 Targets에 끌어다 놓는다.

## 6. 촬영 연출 (`PhotoFlash`)

찍는 순간 화면이 하얗게 번쩍이고 플래시 빛이 켜진다. 이상현상이 찍혔으면 그 자리에서 빛 알갱이가 가운데로 빨려 들어가며 반짝인다('카메라에 가두기'). CameraApp의 Taken·Captured 이벤트만 듣기 때문에 판정에는 영향이 없다. Capture Clip에 '슉' 소리를 넣으면 같이 난다.

## 7. 복도 포스터

`Poster_NP_*.png` 12장이 있다. 대부분은 평범한 학교 게시물(해커톤, 캡스톤 발표, 분리수거, 화재 대피 등)이다. 몇 장은 은근히 이상하다.

- 분실물에 '고래 인형'과 '사과 1개'가 있다.
- '새벽 3시의 공학관' 세미나가 매일 03:00에 열린다.
- 야간 순찰 안내에 '근무자를 따라오지 마세요'가 적혀 있다.

이상현상 아이디어(고래, 사과 회의)와 은근히 이어진다. 생성기가 `Assets/Textures/Posters`의 이미지를 자동으로 쓰므로 포스터 섞기만 하면 된다.

## 문제가 생기면

- **콘솔 에러:** 대부분 컴포넌트 이름 뒤 대괄호(`[SkylightRain]` 등)로 시작한다. 경고 내용대로 칸을 채운다.
- **분홍색으로 보임:** 컴포넌트 ⋮ → Reset으로 셰이더 칸을 다시 채운다.
- **`NightPatrol.Look` 컴파일 에러:** URP 어셈블리 이름이 다르면 asmdef의 references를 확인한다.
- **화면 효과가 안 보임:** 카메라의 Post Processing이 켜져 있는지 확인한다.
- **빗줄기가 가로로 뚱뚱함:** 머티리얼의 `빗줄기 방향 = U` 값을 0으로 바꾼다.
- **유리 방울이 회색:** PC_RPAsset의 Opaque Texture가 켜져 있는지 확인한다.
